# 副食菜單與用餐時段更新（2026-10-19 台北）

## 時段的含義

介面使用「用餐日期／用餐時間」。以使用者希望用餐／取餐的時點檢查優惠時段，沒有自動扣除備餐或配送時間。

肯德基原先把早餐券 08:00–10:30 與一般餐券 10:30–23:00 合併成一段；這只是至少有某種優惠存在的範圍，不代表所有餐點可以在整段時間買到。現在固定列出符合所選品牌、日期、取餐方式的早餐與一般餐點時段，不因選了某種主餐而隱藏另一餐期；每段旁標示所選餐點適用、不適用或實際適用的較短範圍。有指定餐點時，取各餐點優惠時段的交集。人數、預算不會改變這項計算。份量、限購與總筆數是否能滿足，仍由完整組合搜尋判定。找到完整方案後，方案時段另取實際使用券的交集。

未取得供餐時分的資料顯示「完整供餐時段待門市確認」，不以 00:00–24:00 代表營業時間。

## 必勝客官方單點

資料頁面：

- https://www.pizzahut.com.tw/order/?mode=step_2&ct=5&cu=1701
- https://www.pizzahut.com.tw/order/?mode=step_2&ct=6&cu=30

已對照 34 個副食／甜點商品規格，合計 28 種餐點身分。單點商品存於 `menuOffers`，與外部優惠券加官方查碼的 `offers` 分開保存；計算時兩者均可被選取，以實際價格比較。單點使用官方商品連結，不產生虛構優惠碼，也不聲稱已確認特定門市庫存。

官方單點現階段只納入官方網站外帶估算。飲料與調味包不算作本次新增的副食。沒有明示數量的雞球、豬肉條以「份」計；拼盤與禮盒沒有逐項數量時保留整份／盒，不猜成分數量。雞柳條、烤雞與原塊炸雞各自保留身分，墨西哥辣椒芝心腸也不與舊款火辣辣芝心腸合併。

下午茶移除前 8 種的截斷，按鹹點、甜點、拼盤與烤雞呈現所有符合店家、日期與通路的已辨識品項。

## 期間與更新

榴槤起司冰淇淋的官方商品頁明載「期間限定口味售完為止」：
https://www.pizzahut.com.tw/order/?mode=step_2&p_id=18168

這類商品標示期間限定、售完為止；沒有公告結束日就不填造日期。僅有 NEW 標籤不推斷成有固定期限。每週原有資料更新流程同時重讀官方單點頁與限定註記；成功讀取後已下架商品會移除。失敗時保留原讀取時間，不延長有效性。超過 8 天未更新的單點資料，或用餐時間超出該次資料的複查範圍，停止參與估算；此範圍是資料新鮮度限制，並非活動截止日。

新增／更名而未能對照的商品進入 `pizzahutMenu.pending`，不猜餐點與數量。價格不是單一固定數字時不納入。內容及價格與快照簽章不符時停止推薦。

## 驗證

測試涵蓋早餐與一般時段分界、設定微調、餐點時段交集、單點實際參與計算、數量／價格綁定、過期快照、未知品項、來源失敗及下架移除。既有優惠券查碼流程與單一 HTML 建置維持原有檢查。
