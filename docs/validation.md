# v0.5 驗證紀錄

2026-10-17，Windows，Node.js 24.19，Python 標準函式庫。35 組 Node 測試與 16 組 Python 測試通過，共 51 組；最後的介面證據顯示與失敗保留調整另重跑相關建置及解析測試通過。

## 自動驗證範圍

- 計算：固定券價、限購、會員／APP、逐單費用、未知外送費不當零、台北午夜與不連續日期。
- 100 組固定亂數小型資料，用獨立使用次數向量笛卡兒積枚舉，對照正式搜尋最低總額。
- 五種主餐任意非空子集、每種硬需求、混搭份量、中文解析、點心種類與份量。
- 換購逐杯差額、同券混選、替換而非重複加餐、同價中飲替換、限購與 20:00 後換中薯。
- 平台、取餐、資格、付款分開；未知不標確認；已知不符排除；局部官方證據須符合產品識別及期限。
- 五個 feed 格式、前導零碼、確切價、互斥選項、數量不符待解析、包裝與顆數、同碼衝突、原始觀察不覆寫、失敗保留。
- 即時資料唯一碼、數量與品項有效、報告一致、衝突與待解析不進候選。
- 單一 HTML 四個內嵌 script 語法、DOM ID 存在且不重複、安全編碼 JSON、來源以文字節點呈現、無外部執行依賴。

固定價格案例在 `tests/fixtures/`，即時資料另做完整性驗證，避免優惠改價使預期答案跟著改寫。

## 資料與效能觀察

五個來源實際下載成功，解析保留下載時間與內容雜湊。1,964 筆紀錄去重為 1,167 個品牌／券碼：1,035 估算、92 衝突、40 待解析。

六人披薩＋炸雞、一般點心：安全移除被更便宜等效候選覆蓋的項目後，160 候選、7,458 狀態，約 333 毫秒完成，估算 605 元。六人紙包雞＋義大利麵＋冰奶茶：154 候選，約 1.8 秒達搜尋上限，找到各三份主餐與六杯飲料的 1,103 元方案，未證明最低。這些是本機單次觀察，不是手機效能或可兌換報價保證。
