## 更新器實作與尚未驗證之處

採 Python 標準 `HTMLParser` 建樹，按語意容器與區塊解析，不使用全頁價格正規表示式。沒有聲稱某個未觀察到的 CSS selector 是真實網站結構。

合成片段測試覆蓋：主文邊界、段落／表格、原價與優惠價、同碼衝突、合併儲存格、條件區塊切換、未知選項、多段效期、逾時及部分品牌失敗。

**尚缺：**真實原始 HTML 對照、兩次真實更新、官方逐券核對、排程實際觸發、實際門市價格與限購。若 GitHub 首次執行顯示 `article/main` 邊界不匹配，必須先從實際 HTML 校正容器，不能改為整頁扁平解析。

來源更新失敗時：保留原始餐點、價格及各券讀取時間；只更新嘗試時間與錯誤。來源狀態與各券時間分開保存。
