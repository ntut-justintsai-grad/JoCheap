# v0.2 點心與分餐修正

使用者指出第一版缺少點心選項。確認後，問題同時存在於餐點類型、來源優惠收錄與多選一配置的瀏覽呈現。

## 這次修正

- 新增 13 種快捷點心按鈕，支援多選；完整餐點選單仍可新增湯品、飲料與拼盤。
- 補入薯金幣大小份、雞軟骨、德國／辣芝心腸、鱈魚塊、巧克力／麻糬 QQ 球、薯餅、大福、拼盤等獨立類型。
- 不同 QQ 球維持獨立需求，不把所有圓形點心或雞肉點心混算。
- 新增來源優惠與多選一配置；目前 41 筆紀錄仍是部分收錄，不是兩品牌完整菜單或全券清單。
- 優惠瀏覽可切換配餐；分類篩選後會先顯示包含該品項的配置，加入需求時只加入當前配置。
- 超蝦拼盤只計一份拼盤；原文沒有明確數量的超蝦塊、魚圈圈、QQ 球與大薯，不拆成猜測的單品數量。
- 個人餐每人包含主餐、小薯與小杯飲料；配餐可改蛋撻。一般漢堡滿足獨立主餐後，不再被列為額外餐點。
- 共享餐預設加入每人一顆蛋撻，也能換成鹹點；套餐既有點心直接抵需求。
- 計算加上可證明的剪枝，解決擴充點心後常用六人查詢碰到原先搜尋時間上限的問題；中止時仍不宣稱最低價。
