# 肯德基官方餐點說明優先

2026-10-18 調整：KCouper 只用來發現優惠碼與商品代碼。每週直接向官方 `https://olo-api.kfcclub.com.tw/menu/v1/GetQueryFoodDetail` 查詢，原文與查詢參數保存在 `data/kfc_descriptions.json`。

- 基本餐點依 `FoodDetail[0].Intro`，保留原文及原品項名稱。
- 套餐價優先採 Intro 所載價格。`Original_Price` 有時不包含餐內飲料等必要組件，不直接視為整套餐價。
- Intro 未載價格時，僅在完整預設餐點及名稱均與 Intro 一致時，加總官方 `Original_Price + MinCount × 第一選項 MListPrice`；否則保留待確認。
- `Details` 與說明不一致時，不覆蓋基本配置，不加入未確認的替換。畫面另列點餐明細與差額，供使用者核對。
- 說明、單位、選項或價格無法確認的碼仍保留查詢原文，等待重查，不退回 KCouper 預設組合。
- 查詢失敗沿用相同優惠碼、商品代碼與參考門市的上次成功官方說明，保留原查詢時間。首次失敗無可用快取時不參與配餐。

## 供應範圍

參考門市為台北雙連店（TWI104）。快取記錄日期、餐期、取餐方式與 `SoldOut`。售罄標示僅限該門市查詢當下；本工具尚無使用者指定門市的即時庫存查詢，因此保留基本餐單估算並明示其他門市未核對，不把單店售罄推論為全台不能用，也不宣稱查碼成功即可購買。
