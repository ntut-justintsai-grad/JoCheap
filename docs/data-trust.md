# 資料與推薦規則

2026-10-18 更新：預設使用全來源估算，取消只准五張官方基本券參與配餐的門檻。

## 收錄與計算

五個來源的每筆記載均保留，依品牌／券碼分組。`sourceVersions` 保存各來源完整餐點、價格、替換差額、日期、通路與資格，不能跨版本拼接。來源有差異的版本也可以估算，但顯示差異原因；同一餐單不會同時採用同碼的兩種矛盾版本。

有完整餐點與固定價格的版本可參與估算。缺價、未完整辨識的餐點與選項保留原文，不造價、不猜份量；具加購前置條件且尚未建模者不當獨立套餐計算。所有券碼可搜尋，實際可用版本仍依需求、日期、品牌、資格及下單方式篩選。

使用者可改選「排除來源差異」或「只用官方核對」。多來源一致只代表記載一致，並不等於官方保證。來源互相轉載也不是獨立的官方證據。

## 餐點身分與替換

紙包雞、原塊炸雞、飯、雞柳及不同蛋撻分開記錄。結構化資料以預設餐點與明示替換項為準，不把舊活動名稱直接當成內容。例：標題含紙包雞但預設是兩塊炸雞時，顯示預設炸雞；選紙包雞才扣除炸雞、加入一份紙包雞及來源差額。保留名稱差異說明與原始記載。

## 時間與限制

每週日 08:17（台北）擷取解析，手動可立即更新；GitHub 排程可能延遲。推送僅在七天到期或解析器版本變更時重新解析。來源失敗保留其舊資料與原成功時間；讀取時間不是逐券重新查核時間。含超過八天的來源記載會提示較舊資料。

既有的有效日期、時段、會員、個人券、付款、通路與限購條件仍生效。來源未載明的條件可在估算模式納入並明示待確認；使用者也能關閉未知下單方式。未明限購上限按最多訂單數估算，不表示官方允許重複或分筆購買。未知外送費不算零元。

## 額外官方核對

`data/official_reviews.json` 與 `data/official_evidence/` 保留特定基本配置的官方清單、券面雜湊、日期與查核範圍。只有查核未過期、內容綁定相符及條件符合的配置才標「官方基本配置已核對」。來源改價、券面或條件異動、期限過期或官方讀取失敗即撤銷此標示；全來源估算仍保留對應來源版本並清楚標示。

`data/quality_report.json` 提供逐券解析狀態及問題。結果可展開原文、來源連結、本站讀取與上游更新時間。估算價格與資訊可追溯，實際門市供應及結帳仍以官方當次結果為準。
